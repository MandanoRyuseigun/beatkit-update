# beatkit-update

BeatKit（BOOTH で配布している Windows アプリ）が、起動したときに「新しい版があるか」を確かめるためのファイルです。
アプリ本体やソースコードはここにはありません。

## 新しい版を出すときの手順（持ち主用）

1. BOOTH の商品ページに新しい zip を上げる
2. `latest.json` の `version`・`date`・`message` を書き換えて push する
   - `version` はアプリの `VERSION`（例 `1.0.1`）と同じにする
   - `message` は画面のお知らせに出る一言（300文字まで）
   - `url` は通常版・無料版それぞれの BOOTH の商品ページ
3. 数分以内に、古い版のアプリを起動するとお知らせが出る

**注意**：`version` を、まだ BOOTH に上げていない版にしないこと（お知らせが出ても受け取れなくなります）。
